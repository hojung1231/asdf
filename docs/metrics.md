# HUGGY 2.5 기록 항목

앱과 큰 위젯·미니 위젯에 허기 / 집중력 / 스트레스의 버튼 6개씩을 3열로 동시에 표시합니다.
탭이나 모드 전환 없이 18개 버튼을 직접 누릅니다. 각 항목은 별도의 로컬 기록을 사용합니다.
기존 `history/points` 허기 기록과 허기 친구 공유는 유지됩니다.
집중력과 스트레스는 현재 휴대폰에만 저장하며 친구 서버에 보내지 않습니다.

- 각 열의 입력은 6→1 순서의 세로 6행입니다. 같은 항목에서 1분 안에 다시 누르면 마지막 값을 수정합니다.
- 허기 그래프는 기존처럼 허기 증가 시 선형, 식사 시 계단형으로 연결합니다. 기존 점수식을 유지합니다.
- 집중력은 6 초집중 ~ 1 집중 불가입니다. 점수는 기기 현지 시각의 **오늘 08:00~17:00**에 남긴
  기록만 사용합니다. 08:00과 17:00 기록을 포함하고, 업무시간 밖이나 다른 날짜 기록은 제외합니다.
  시간에 가중한 평균 단계 `v`에 대해 `(v - 1) × 20`점입니다.
- 스트레스는 6 극심함 ~ 1 매우 편안함입니다. 위젯·앱 점수는 **기록 시작부터 마지막 기록까지 전체 기간**의
  시간 가중 평균을 사용합니다. `(6 - v) × 20`점으로 스트레스가 낮을수록 점수가 높습니다.
- 집중력과 스트레스는 연속 기록 사이를 선형으로 연결하고 그 적분으로 시간 평균을 계산합니다.
  첫 기록 이전, 마지막 기록 이후의 미관측 시간을 임의로 채우지 않습니다. 대상 기록이 하나면 그 단계로 계산하며,
  대상 기록이 없으면 0점 대신 ‘기록 없음’을 표시합니다.
- 하나의 전체 너비 그래프에 허기(민트)·집중력(파랑)·스트레스(분홍) 기록선을 표시합니다.
  세 항목의 오늘 첫 기록부터 마지막 기록까지 동일한 시간축을 사용합니다. 누적 평균선과 친구 소식은 제거했습니다.
  평균은 점수 계산에만 사용하며 세 점수는 동시에 표시합니다.
- 각 열 제목을 누르면 해당 기록을 수정하고, 점수를 누르면 항목별 일별 점수 이력을 엽니다. 스트레스의 일별 행은 해당 날짜 전체 기록의 점수이며,
  화면의 누적 점수와 구분합니다. 항목별 수정·초기화는 다른 항목에 영향을 주지 않습니다.

위젯은 6개 입력 버튼을 세로로 배치하기 위해 큰 버전 최소 높이 620dp, 미니 버전 420dp를 사용합니다.
기존 위젯이 낮은 높이를 유지하면 홈 화면에서 세로 크기를 늘려 주세요.
